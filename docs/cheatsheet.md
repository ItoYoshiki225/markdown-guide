# ⚡ Markdown 早見表

## 基本

| やりたいこと | 書き方 |
| :--- | :--- |
| 見出し | `# H1` / `## H2` / `### H3` |
| 太字 | `**太字**` |
| 斜体 | `*斜体*` |
| 取り消し線 | `~~取り消し~~` |
| 改行 | 行末に半角スペース 2 つ、または `<br>` |
| 段落 | 空行を 1 行入れる |
| 箇条書き | `- 項目` |
| 番号付き | `1. 項目` |
| ネスト | 半角スペース 2 つでインデント |
| リンク | `[テキスト](URL)` |
| 画像 | `![代替テキスト](パス)` |
| 水平線 | `---` |
| インラインコード | `` `code` `` |

## 中級

| やりたいこと | 書き方 |
| :--- | :--- |
| コードブロック | ` ```言語名 ` 〜 ` ``` ` |
| 引用 | `> 引用文` |
| タスクリスト | `- [ ] 未完了` / `- [x] 完了` |
| 表 | `\| A \| B \|` + `\| --- \| --- \|` |
| 表の揃え | `:---` 左 / `:---:` 中央 / `---:` 右 |
| 脚注 | `本文[^1]` + `[^1]: 注釈` |
| エスケープ | `\*` `\#` など |
| 参照リンク | `[テキスト][id]` + `[id]: URL` |
| ページ内リンク | `[テキスト](#見出し名)` |

## 上級（GitHub）

| やりたいこと | 書き方 |
| :--- | :--- |
| アラート | `> [!NOTE]` / `[!TIP]` / `[!IMPORTANT]` / `[!WARNING]` / `[!CAUTION]` |
| 図 | ` ```mermaid ` |
| 数式（インライン） | `$E = mc^2$` |
| 数式（ブロック） | `$$` 〜 `$$` |
| 折りたたみ | `<details><summary>タイトル</summary>` 〜 `</details>` |
| キー表記 | `<kbd>Ctrl</kbd>` |
| Issue 参照 | `#123` |
| Issue 自動クローズ | `Closes #123` |
| メンション | `@username` |
| 絵文字 | `:rocket:` |
| コメント | `<!-- 非表示 -->` |

## よくあるミス

| 症状 | 原因と対処 |
| :--- | :--- |
| 見出しにならない | `#` の後に半角スペースがない |
| 改行されない | 行末スペース 2 つか `<br>` が必要 |
| リストが崩れる | 前の段落との間に空行がない／インデント幅が不揃い |
| 太字にならない（日本語） | `**` の前後に半角スペースを入れる |
| 文章が見出しになった | 文章の直下に `---` を書いた → 間に空行を入れる |
| 表が崩れる | 列数が行ごとに違う／セル内に `\|` がある |
| 画像が出ない | パスの間違い（大文字・小文字も区別される） |
