## 1. 見出し

行頭に `#` を付けると見出しになります。`#` の数がレベル（1〜6）です。

```markdown
# 見出し1（ページのタイトル。1ファイルに1つだけ）
## 見出し2（大きな章）
### 見出し3（節）
#### 見出し4
```

> [!TIP]
> `#` の後ろには **半角スペース** が必要です。`#見出し` は見出しになりません。

---

## 2. 段落と改行

**空行を 1 行入れる** と段落が分かれます。

```markdown
これは1つ目の段落です。

これは2つ目の段落です。
```

段落の中で改行だけしたい場合は、次のどちらかを使います。

```markdown
行末に半角スペースを2つ入れる  
と改行されます。

または行末に<br>タグを書きます。
```

> [!NOTE]
> GitHub のコメント欄や Issue では、普通に Enter で改行しても反映されます。
> ただし `.md` ファイルでは反映されないので注意しましょう。

## 3. 強調（太字・斜体）

| 書き方 | 表示 |
| :--- | :--- |
| `**太字**` | **太字** |
| `*斜体*` | *斜体* |
| `***太字かつ斜体***` | ***太字かつ斜体*** |
| `~~取り消し線~~` | ~~取り消し線~~ |

> [!TIP]
> 日本語の文中で太字が効かないときは、`**` の前後に半角スペースを入れると直ることがあります。
> 例：`これは **重要** です`

---

## 4. 箇条書きリスト

行頭に `-`（ハイフン）+ 半角スペースを書きます。

```markdown
- りんご
- みかん
  - 温州みかん
  - デコポン
- ぶどう
```

表示：

- りんご
- みかん
  - 温州みかん
  - デコポン
- ぶどう

ネスト（入れ子）するときは **半角スペース 2 つ** でインデントします。

---

## 5. 番号付きリスト

```markdown
1. 要件定義
2. 設計
3. 実装
4. テスト
```

表示：

1. 要件定義
2. 設計
3. 実装
4. テスト

> [!TIP]
> 全部 `1.` と書いても自動で連番になります。途中に項目を挿入しても番号を直さなくて済むので便利です。

## 6. リンク

```markdown
[表示するテキスト](https://github.com)
[同じリポジトリ内の別ファイル](02-intermediate.md)
[ページ内の見出しへ](#1-見出し)
<https://github.com>
```

表示：

- [表示するテキスト](https://github.com)
- [同じリポジトリ内の別ファイル](02-intermediate.md)
- [ページ内の見出しへ](#1-見出し)
- <https://github.com>

> [!NOTE]
> ページ内リンクの書き方：見出しの文字を小文字にして、スペースを `-` に置き換え、記号を除いたものになります。
> 例：`## 3. 強調（太字・斜体）` → `#3-強調太字斜体`

---

## 7. 画像

リンクの先頭に `!` を付けると画像になります。

```markdown
![代替テキスト（画像が表示されないときの説明）](../assets/images/sample.png)
```

> [!TIP]
> 画像はリポジトリ内の `assets/images/` にまとめて置き、**相対パス** で参照するのがおすすめです。
> 代替テキストはアクセシビリティのため、必ず書きましょう。

---

## 8. 水平線

`---` を単独の行に書くと区切り線になります。

```markdown
上の内容

---

下の内容
```

> [!WARNING]
> 文章の直下に空行なしで `---` を書くと、上の文章が **見出し2** として扱われてしまいます。前後に空行を入れましょう。

---

## 9. インラインコード

文中のコマンドやファイル名は `` ` ``（バッククォート）で囲みます。

```markdown
`git push` コマンドで `main` ブランチに反映します。
```

表示：`git push` コマンドで `main` ブランチに反映します。

## 練習問題

次の表示になるように Markdown を書いてみましょう。

> ### 買い物リスト
>
> **今日中に** 買うもの：
>
> 1. 牛乳
> 2. パン
>    - 食パン
>    - クロワッサン
>
> 詳しくは [スーパーのサイト](https://example.com) を参照。

<details>
<summary>解答例を見る</summary>

```markdown
### 買い物リスト

**今日中に** 買うもの：

1. 牛乳
2. パン
   - 食パン
   - クロワッサン

詳しくは [スーパーのサイト](https://example.com) を参照。
```

</details>
