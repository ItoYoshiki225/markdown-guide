## 1. 表（テーブル）

`|` で列を、`-` でヘッダーの区切りを表します。

```markdown
| 項目 | 担当 | 進捗 |
| :--- | :---: | ---: |
| 設計 | 田中 | 100% |
| 実装 | 佐藤 | 60% |
| テスト | 鈴木 | 0% |
```

表示：

| 項目 | 担当 | 進捗 |
| :--- | :---: | ---: |
| 設計 | 田中 | 100% |
| 実装 | 佐藤 | 60% |
| テスト | 鈴木 | 0% |

### 揃え方

| 書き方 | 揃え |
| :--- | :--- |
| `:---` | 左揃え（文章向き） |
| `:---:` | 中央揃え（短いラベル向き） |
| `---:` | 右揃え（**数値** 向き） |

### 表の中で使えるテクニック

| やりたいこと | 書き方 |
| :--- | :--- |
| セル内で改行 | `<br>` を使う |
| `\|` を文字として表示 | `\|` とエスケープ |
| 空のセル | 何も書かない（`\| \|`） |

> [!TIP]
> 表は手で揃えるのが大変です。VS Code の「Markdown All in One」拡張なら `Alt + Shift + F` で自動整形できます。

## 2. コードブロック

バッククォート 3 つで囲み、直後に **言語名** を書くとシンタックスハイライトされます。

````markdown
```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Markdown!");
    }
}
```
````

表示：

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Markdown!");
    }
}
```

### よく使う言語名

| 言語 | 指定 | 言語 | 指定 |
| :--- | :--- | :--- | :--- |
| Java | `java` | SQL | `sql` |
| JavaScript | `javascript` / `js` | シェル | `bash` / `shell` |
| TypeScript | `typescript` / `ts` | YAML | `yaml` |
| Python | `python` | JSON | `json` |
| HTML | `html` | 差分 | `diff` |
| CSS | `css` | プレーンテキスト | `text` |

### 差分（diff）の表示

```diff
- const timeout = 3000;
+ const timeout = 5000;
```

> [!TIP]
> コードブロックの中に ```` ``` ```` を書きたいときは、外側をバッククォート **4 つ** で囲みます。

## 3. 引用

行頭に `>` を付けます。重ねると入れ子になります。

```markdown
> 顧客からの要望：
> 検索結果を CSV でダウンロードしたい。
>
> > 補足：Excel で開けること。
```

表示：

> 顧客からの要望：
> 検索結果を CSV でダウンロードしたい。
>
> > 補足：Excel で開けること。

## 4. タスクリスト

```markdown
- [ ] テストケースの作成
- [ ] 結合テストの実施
```

表示：

- [x] 要件定義書のレビュー
- [x] テスト計画書の作成
- [ ] テストケースの作成
- [ ] 結合テストの実施

> GitHub の Issue / PR では、チェックボックスをクリックして直接オン・オフできます。

## 6. エスケープ

Markdown の記号をそのまま表示したいときは `\`（バックスラッシュ）を前に付けます。

```markdown
\*これは斜体になりません\*
\# これは見出しになりません
```

表示：

\*これは斜体になりません\*

\# これは見出しになりません

エスケープできる主な記号：`\` `` ` `` `*` `_` `{}` `[]` `()` `#` `+` `-` `.` `!` `|`

## 7. 参照スタイルのリンク

同じ URL を何度も使うときや、本文をスッキリさせたいときに便利です。

```markdown
詳しくは [公式ドキュメント][gfm] と [チートシート][cheat] を参照してください。

[gfm]: https://github.github.com/gfm/
[cheat]: ./cheatsheet.md
```

表示：

詳しくは [公式ドキュメント][gfm] と [チートシート][cheat] を参照してください。

[gfm]: https://github.github.com/gfm/
[cheat]: ./cheatsheet.md

## 8. 折りたたみ

長いログや補足情報は折りたたんでおくと読みやすくなります。

```markdown
<details>
<summary>エラーログ全文</summary>

ここに長いログを書く（前後に空行を入れると中で Markdown が使えます）

</details>
```

表示：

<details>
<summary>エラーログ全文</summary>

```text
java.lang.NullPointerException
    at com.example.Service.execute(Service.java:42)
    at com.example.Controller.handle(Controller.java:18)
```

</details>
